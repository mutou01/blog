总结一份 **Tailscale + RustDesk** 的安装与使用教程。这两者配合使用，能让你随时随地、安全且流畅地远程控制你的 Windows 电脑。

---

### 📖 核心概念：它们各自的作用

- **Tailscale**：负责“修路”。基于 WireGuard 协议，在手机和电脑之间建立一条点对点的加密虚拟局域网（VPN），让它们像在同一个路由器下一样互联。
- **RustDesk**：负责“开车”。是一款开源的远程桌面软件，负责传输屏幕画面和操作指令。

**组合优势**：通过 Tailscale 的虚拟 IP 直连，可以绕过 RustDesk 的官方公网中继服务器，实现**更低延迟、更高画质、更安全（数据不经第三方）** 的远程控制。

---

### 第一步：安装 Tailscale（打通网络）

#### 1. 在 Windows 电脑上安装
1. 访问 [Tailscale 下载页面](https://tailscale.com/download)，下载 Windows 版本的 `.exe` 安装包。
2. 双击安装包，按提示完成安装。
3. 安装完成后，在系统托盘找到 Tailscale 图标，右键点击并选择 **“Log in...”**，用浏览器完成登录（如 Google、Microsoft 账号）。

#### 2. 在 Android 手机（华为手机）上安装
**如果手机没有 Google Play 商店**，使用以下方式：
- **官网下载 APK**：用手机浏览器访问 [Tailscale 安卓下载页](https://pkgs.tailscale.com/stable/#android)，下载“Universal APK”文件。
- **安装 APK**：若系统提示风险，请参考文章末尾的“华为手机安装注意事项”解决。
- **登录**：安装后打开 App，选择“Sign in with Google”或“Sign in with other”完成登录。

> **验证**：登录后，在 Tailscale 界面中你应该能看到两台设备（Windows 和 Android）都显示为“在线”状态，并各自分配了一个 `100.x.x.x` 的虚拟 IP。

---

### 第二步：安装 RustDesk（远程桌面）

#### 1. 在 Windows 电脑上安装（被控端）
1. 访问 [RustDesk 官方 GitHub 发布页](https://github.com/rustdesk/rustdesk/releases)，下载适合你电脑的 `.exe` 文件（通常是 `rustdesk-版本号-x86_64.exe`）。
2. 双击安装，按默认选项完成即可。

#### 2. 在 Android 手机上安装（控制端）
- **从官网下载 APK**：访问 [RustDesk 官网下载页](https://rustdesk.com/zh/)，下载安卓版本的 APK 文件。
- **安装并授权**：安装后打开 App，根据提示允许所需的屏幕录制和悬浮窗权限。

---

### 第三步：配置 RustDesk，使用 Tailscale 直连

这是实现高速远程控制的关键步骤。

#### 1. 在 Windows 电脑（被控端）配置
1. 打开 RustDesk，点击主界面左侧 ID 旁边的 **`...`** 菜单，选择 **“设置”**。
2. 切换到 **“安全”** 选项卡。
3. **勾选“启用直接IP访问”**（这是允许通过 Tailscale IP 连接的开关）。
4. 在下方设置一个 **“永久密码”**，并记住它。这样以后连接就不需要每次都看临时密码了。

#### 2. 在 Android 手机（控制端）连接
1. 打开手机上的 RustDesk App。
2. 在“远程设备 ID”输入框中，**不要输入电脑的 RustDesk 公共 ID**，而是输入 Windows 电脑的 **Tailscale 虚拟 IP 地址**（例如 `100.114.203.70`）。
3. 点击“连接”，输入你刚刚在 Windows 上设置的**永久密码**。
4. 连接成功后，你就可以在手机上流畅地操作 Windows 桌面了。

---

### 🔧 华为手机安装应用注意事项

安装 Tailscale 或 RustDesk APK 时，若华为手机提示“发现恶意应用”并阻止安装，可按以下顺序操作：

1. **关闭增强防护**：进入“设置 > 系统和更新 > 纯净模式”，关闭“增强防护”。
2. **关闭安全检测**：进入“设置 > 安全 > 更多安全设置”，关闭“外部来源应用安全检测”。
3. **授权安装器**：在“设置 > 安全 > 更多安全设置 > 安装未知应用”中，给“文件管理”或“浏览器”开启“允许安装未知应用”。
4. **尝试断网安装**：开启飞行模式，断开所有网络，再点击 APK 文件安装。
5. **使用 ADB 命令**：若以上均无效，可用电脑 ADB 命令安装（需开启 USB 调试）：`adb install -r -d -t "APK文件路径"`。

---

### ❓ 常见问题

- **连接失败，提示“Failed to connect to 100.x.x.x:21118”**：请检查 Windows 端 RustDesk 是否已开启“启用直接IP访问”，并设置了永久密码。
- **Tailscale 无法直连**：确保两台设备登录的是同一个 Tailscale 账号，且 App 内状态均为“在线”。如果网络环境过于复杂，Tailscale 会自动降级为中继模式，速度会变慢但依然可用。
- **RustDesk 画面卡顿**：请检查 Tailscale 连接状态，如果是中继模式（Relay），可尝试重启两端 App 重新建立直连（P2P）。
