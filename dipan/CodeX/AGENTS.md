# Obsidian Vault 规范

你正在访问一个技术知识库。请遵守以下规则：

- 所有新笔记必须包含 YAML frontmatter，包括 `tags` 和 `created` 字段。
- 修改已有笔记时，永远不要更改或删除其已有的 frontmatter。
- 笔记命名遵循 `主题-关键词.md` 的格式。
- 回答问题时，优先引用 Vault 中的笔记内容，并注明来源。

## 写作规范

- 新笔记的 `created` 字段使用 `YYYY-MM-DD` 格式。
- `tags` 字段使用 YAML 列表格式，例如：

```yaml
---
tags:
  - example
created: 2026-05-19
---
```

- 笔记内容以 Markdown 编写，标题层级从 `#` 开始，避免跳级。
- 技术概念、命令、文件路径、API 名称使用反引号标注。

## 编辑规范

- 编辑已有笔记前，先读取原文并确认是否存在 YAML frontmatter。
- 若已有 frontmatter，只能在用户明确要求时追加字段；不得重排、删除或改写既有字段。
- 若已有笔记缺少 frontmatter，除非用户明确要求补齐，否则不要自动添加。
- 尽量保持改动范围最小，不进行与任务无关的整理、改名或格式化。

## 引用规范

- 回答 Vault 相关问题时，优先基于本 Vault 中的笔记、目录和文件内容作答。
- 引用笔记时注明来源路径，例如：`wiki/主题-关键词.md`。
- 如果 Vault 中没有足够信息，应明确说明，并区分“来自 Vault 的内容”和“推断或外部知识”。
