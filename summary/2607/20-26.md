## Learn:
1.个人运行 AI 模型，可以选择两种硬件。
独立显卡，英伟达的RTX 5090，显存32GB。
芯片组（CPU + 板载显卡 + 板载内存）的家用电脑，AMD 公司 Strix Halo 芯片组（具体型号 Ryzen AI Max+ 395），128GB内存。
独显的算力远大于板载芯片组，32位浮点数计算场景下，独显是芯片组的7倍，而价格是芯片组的1.5倍。
```
独立显卡（RTX 5090）：104.8 TFLOPS
板载芯片组（AMD Ryzen AI Max+ 395）：14.8 TFLOPS
```
可真实使用场景，并非无脑选独显，因为 AI 模型只要参数规模稍大，5090就运行不了。
70b 参数的模型，每个参数使用4位精度，将所有参数的权重读入内存，大约需要 32.6GB，超出了5090的显存大小，它根本跑不起来。
而芯片组的板载内存则有 128GB，为显卡与 CPU 共用，称为“统一内存”，能够分出尽可能多的内存给单个处理器，所以能处理内存消耗很大的 AI 模型。
苹果的 M 系列芯片也是这种“统一内存”架构，除了内存容量大，它的价格也比独显低。
但部署 AI 模型，我们不仅要考虑内存大小，也要考虑“内存带宽”，这就是板载芯片组的弱点。
```
独立显卡（RTX 5090）：1792GB/s
板载芯片组（AMD Ryzen AI Max+ 395）：256GB/s
```
它决定了AI 模型生成 token 的速度，40GB 的模型，一秒只能生成6个token。
好在为了节省计算量，出现了“混合专家模型（MoE）”这种架构，它计算 Token 时，不需要读取全部参数，只需要激活一部分参数即可。
一般来说，是激活1/10，那么生成 token 的速度也就快了10倍。
这么看来，板载芯片组是会是更好的选择，但别忘了算力。
由于算力低，板载芯片组处理提示词也慢，70B 的模型，提示词处理速度是每秒95个 Token。那么，用户提交4000个 token 的文档，大约需要40秒才能处理完，然后才能输出第一个 Token。
而现有顶尖开源模型，上下文容量一般是1M，600K的上下文，就需要100min，这无疑是不可容忍的。
因此，板载芯片组适合中等规模的 MoE 模型，而且上下文不能太长。
独显则需要外接更多的高带宽内存（HBM），保证带宽的前提下，扩大内存。

2.如何保证LLM生成调用tool的入参的稳定性？
靠这 4 层一起做：

Prompt 约束
告诉模型“数组就必须传数组，不要传字符串化 JSON”。

Schema 约束
尽量让工具参数类型简单、少嵌套，减少模型出错空间。

解析层容错
只对已知高频错误做白名单兼容，不能无限兜底。

日志与监控
把原始 tool arguments 记下来，知道模型到底错成什么样，避免盲补。
