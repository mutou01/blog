## Learn:
1.LiteLLM 目前最活跃的开源 LLM 网关，本质是应用和模型 API 的中间层。
解决多模型统一接口，改网关配置就能换模型，不改应用代码。API Key 集中管理，避免泄漏。负载均衡和故障转移，避免单供应商限流影响业务层。限流与配额，给团队设 token 预算，防止烧光公司额度。成本追踪，记录 token 用量，评估成本。Prompt 安全和内容过滤，对输入输出做安全检验，检测提示词注入攻击，过滤隐私、内容安全审核等。语义缓存，语义相似的问题直接返回上次结果，不调 LLM，省钱降延迟，注意相似度阀值和缓存有效期，根据使用场景决定，适合高频重复的问答场景。

2.grill-me使用体验，Superpowers 是一条开发流水线，grill-me 是一个工具，应该与 Superpowers 中的 brainstorming 相对比。
grill-me 重点在于决策树，每次一问，带选项和推荐理由，问题多，问完只给设计共识总览。
没 git，没文档，没计划，全在对话与代码里。
brainstorming 不是文字问答，是选项卡片，问题数量少，决定范围大，问完出完整设计供用户选择。
设计落 spec 文档，存 plan 任务，自己 commit，写提交信息，然后走 Superpowers 的下一个 Skill。
